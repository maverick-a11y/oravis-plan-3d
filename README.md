# Oravis Plan Événement 3D

Outil 3D d'implantation de salle pour ORAVIS : tables, chaises, mobilier lounge, tentes stretch, pistes de danse (avec danseurs animés), guirlandes et décor.

## Utilisation

Tout tient dans un seul fichier, `index.html`. Il suffit de l'ouvrir dans un navigateur, sans installation.

## Mise en ligne avec GitHub Pages

1. Envoie le contenu de ce dossier à la racine du dépôt.
2. Dans le dépôt, va dans **Settings → Pages**.
3. Choisis la source **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
4. Après quelques minutes, le site est disponible à l'adresse `https://<ton-compte>.github.io/<nom-du-depot>/`.

## Remarques

- La bibliothèque 3D (three.js 0.160) et les polices sont chargées depuis Internet : une connexion est nécessaire.
- Les plans enregistrés restent dans le navigateur de chaque utilisateur. Ils ne sont pas partagés entre ordinateurs.
- Certaines fonctions de la version hébergée sur Claude, comme la bibliothèque d'équipe partagée, ne marchent que dans Claude. Le reste fonctionne normalement.
