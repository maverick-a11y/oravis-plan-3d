# Oravis Plan Événement 3D

Outil 3D d'implantation de salle pour ORAVIS (usage interne) : mobilier, tentes stretch, planchers, guirlandes, sols, animations.

## Utilisation

Ouvrir `index.html` dans un navigateur récent (Chrome, Edge, Safari, Firefox). Aucune installation n'est nécessaire : la 3D (three.js) est chargée depuis un CDN, il faut donc une connexion Internet.

- Les plans sont gardés dans le navigateur de chaque personne.
- **Exporter** télécharge le plan au format JSON ; **Importer** le recharge (pour l'envoyer à un collègue).
- La bibliothèque partagée « Équipe » ne fonctionne que dans la version ouverte depuis claude.ai.

## Dernières modifications

- Guirlande guinguette en éventail : contour supprimé, seuls les rayons partent du mât central. La guirlande revient au mât le long des rayons (repassage compté dans le récap).
- Éclairage adouci : ampoules, halo (bloom), faisceaux des projecteurs et soleil moins intenses, en vue jour comme en vue soirée.
- Bouton « Lumières » (barre d'outils du bas) : deux réglages, Ampoules (brillance, 50 % par défaut) et Éclairage (lumière projetée sur le décor), gardés sur l'appareil.
- Tente stretch : option « Guirlande scintillante entre 2 mâts » (travée gauche ou droite sur la 10,5 × 21 m). Chaque brin part du sol d'un côté, passe par-dessus le filin entre les mâts et s'accroche au bord de la toile en face. Ampoules qui scintillent, métrage et brins comptés dans le récap.
